Open Live Wallpaper is released under the MIT license (see `LICENSE`).

## Textures (CC0 1.0, public domain)
All PBR photo textures come from [ambientCG](https://ambientcg.com) and are licensed CC0. They are used at 1K resolution
(colour and normal maps), converted to JPEG inside `app/src/main/assets/tex`.

| Use | Asset |
|---|---|
| Snow | Snow006 |
| Grass | Grass001 |
| Forest floor | Ground037 |
| Rock | Rock030 |
| Cabin logs | Wood051 |
| Cabin roof | Wood096 |
| Bark | Bark001 |
| Stream bed gravel | Gravel023 |
| Fallen leaves | ScatteredLeaves004 |
| Mud | Ground054 |
| Ice | Ice003 |

The conifer needle texture and the maple leaf cards are generated procedurally at start-up. All 3D geometry
(terrain, trees, cabins, animals, people, props) is generated by code, so there are no third-party models.

## Code
- [stb_image](https://github.com/nothings/stb) by Sean Barrett, public domain (`app/src/main/cpp/stb_image.h`).

## Data
- Weather: [Open-Meteo](https://open-meteo.com), free for non-commercial use, data licensed CC BY 4.0. No API key and no location permission are used; the city is chosen in the settings.
- Sun and moon positions are computed on the device from low-precision astronomical formulas.
